## 🎧 音訊清單與講稿結構

1. **1114 EP01 核心投資思維與三大財務指標**（約 14~15 分鐘，5.07 MB）
   - 2027 資本支出峰值、大跌 20% 送分題、定期定額切三旬、資金金字塔（10%/20%/30%）。
   - ROE 負債陷阱與杜邦分析、毛利率定價權、川湖 9% 資本支出率現場手算與 XQ 查找步驟。
2. **1114 EP02 三大趨勢產業與個股地雷避坑**（約 13~14 分鐘，4.79 MB）
   - ESG 公司治理與 00692、AI 吃電怪獸與國泰全球基建基金、生技長照商機。
   - 台積電本益比三階梯（20~25 便宜送分題、25~30 合理、30~35 貴）、智邦 2345、年化報酬率公式、川湖 vs 基亞/宏達電地雷對照。
3. **1107 深度大課：總經大局、M1B熱錢與主力操盤**（約 14~15 分鐘，4.87 MB）
   - 換位思考學習主力思維、爸爸是美國與科技連動本質、日本國債 260% 與渡邊太太套利交易連鎖風暴。
   - 景氣領先指標 7 項子指標細解、PMI/ISM 榮枯線、M1B/M2 黃金交叉與量價背離、三大保命出場警訊。
