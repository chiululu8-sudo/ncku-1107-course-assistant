## 🎧 最新課程音訊清單（1121 全新 35 分鐘雙大課）

1. **1121 EP01 宏觀大局、插旗策略與三大估價法**（約 16~18 分鐘，5.48 MB）
   - 加權 35,738 點打折八折真相、合併營收柱狀圖持續創高。
   - 三大市場噪音解密（Fed升息、地緣油價、外資長假結帳賣壓）。
   - 「零股插旗策略（Flag-Planting）」戰勝人性（川湖 5,700~6,000 賣飛借鏡）。
   - 三大估價法：股息殖利率（0056 老本池 vs 新型 ETF 陷阱）、景氣股 PBR（加權平均 PBR 眉角）、科技股 PER（Forward EPS 與河流圖五色判讀）。
2. **1121 EP02 黑板手算大公開：個股實戰、魚板竹籤K線與散戶三紀律**（約 19~22 分鐘，6.47 MB）
   - XQ 七大選股因子（毛利 > 40%、資本支出/股本 > 40%、單位換算避坑）。
   - 黑板手算還原：致茂 2360（45.47% 合格、目標價 1,163 元）、川湖 2059（136.7% 超大資本支出與洗盤心戰）。
   - 地雷對照組淘汰原因：創見、振樺電、光聖。
   - 重點個股：台積電（2,000 元送錢買點、保守目標 2,574 元）、奇鋐（水冷目標 4,000 元）、鈊象（98% 毛利、700~740 安全底線）、長榮（溫國信雪球法盲點、正統 PBR 便宜價 191 元）。
   - K 線心戰：魚板與竹籤、鐵鎚線、基亞 17 根無量跌停本夢比毀滅、漲停次日回撤 1/3 掛單絕技。
   - 散戶保命三大紀律：嚴禁融資、每個月落實獲利了結、精研 1~2 檔股性。
