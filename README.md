## 🌟 核心版面與強大功能（完全還原專業看盤系統）

### 1. 頂部搜尋與自選標籤列
- **代號即時查詢**：在頂部輸入任何台股代號（如 `3661`, `2330`, `2059`, `2360`, `3017`, `3293`, `2603`, `0050`, `0056`, `00878`, `TX` 等），按 Enter 或點擊「**查詢**」，全畫面圖表、技術指標、主力籌碼、漲跌機率與成大估價模型即刻全自動毫秒連動！
- **快捷標籤 Chips**：包含 `2330 台積電`、`3661 世芯-KY`、`2059 川湖`、`2360 致茂`、`3017 奇鋐`、`3293 鈊象`、`2603 長榮`、`0050`、`0056`、`00878`、`00919`、`00929`、`TX 台指期`。
- **+ 自選功能**：點擊「+ 自選」即可將任何自訂查詢的個股釘選在頂部快捷標籤列。

### 2. 左側高精度技術看盤區
- **報價抬頭條**：即時呈現最新價格、紅漲綠跌幅、成交量、單量、委買委賣五檔報價。
- **K 線主圖 (Canvas)**：
  - 繪製 50 根高精度 K 線柱與上下影線。
  - **MA5**（黃色）、**MA20**（青色）、**MA60**（洋紅色）均線平滑曲線。
  - **布林通道**（半透明填充區域與上中下軌道線）。
  - **智慧診斷面板**：浮動標註近期最高、近期最低、壓力位、支撐位。
- **成交量副圖**：成交量柱狀圖 + MA5 量均線 + 量能趨勢狀態（量縮整理/放量突破）。
- **KD 副圖**：KD (9,3,3) K線 (紅) 與 D線 (青) 動態走勢，標註 80 超買與 20 超賣基準線。
- **MACD 副圖**：MACD 紅綠能量柱狀圖、DIF 線、MACD 線與多方動能增減標籤。
- **多週期趨勢分析**：60分K (短線)、日K (中線)、週K (長線) 迷你圖與趨勢診斷。
- **技術診斷四格卡**：
  - **關鍵價位**：壓力區、回檔區、支撐區、跌破防守點、強勢突破關鍵。
  - **型態分析**：W底分析與 M頭分析（頸線突破與形態成立驗證）。
  - **主力燈號**：發光大圓燈（偏多布局/觀望/偏空防守）。
  - **短線勝率 (AI強化版)**：Canvas 繪製半圓指針儀表盤。

### 3. 右側分析、預測與成大估價決策
- **技術分析總覽**：綜合評分（大字數值）、趨勢/動能/KD/量能長條圖、方向與均線糾結狀態判定。
- **主力進出 (張)**：最近 5 日三大法人主力增減張數、收盤價、漲跌幅明細表。
- **指標總覽 & 操作建議**：KD、MACD、RSI、均線、布林通道狀態；具體買進策略、進場觀察點、目標價與停損防守點。
- **🔥 漲跌機率預測 (AI模型)**：上漲機率 %、下跌機率 %、盤整機率 %，以及多因子 AI 預測結論。
- **🌟 成大課堂三大估價模型**：
  - 🟢 **便宜價 (低檔布局點)**
  - 🔵 **合理價 (公允中樞)**
  - 🔴 **昂貴價 (分批停利點)**
  - 🎯 **2027 明年預估目標股價** 與 **潛在漲幅空間 (%)**
  - 支援「**微調參數**」，可自訂 Forward EPS 與倍數連動試算。
- **底部三大功能選單**：
  - ⚡ **股海尋寶系統 (課堂 7 大好股票嚴格檢驗清單)**：毛利率 $\ge 40\%$、資本支出/股本 $\ge 40\%$、ROE $\ge 15\%$、負債比 $\le 50\%$、速動比率 $\ge 1.5$、本業成長、預估 EPS 正成長。
  - 🚀 **策略分析選單**：查看三大估價模型推導數學細節與課堂防禦紀律。
  - 🤖 **語音隨身聽 & 3天速查庫**：隨時開啟 1121/1114/1107 大課語音與黑板手算字典。
