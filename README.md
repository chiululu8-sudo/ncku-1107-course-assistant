# 🎓 成大投資實戰 語音學習隨身助教 (NCKU Course Voice Assistant)

本專案為成大投資實戰課程打造，完整收錄課堂錄音精華、逐字對照講稿、黑板手算公式筆記，並建置於 GitHub Pages 線上服務。使用者可透過語音朗讀、逐字稿對照、三大估價法股票試算機與 AI 對話問答深入複習。

### 核心功能總覽：
1. **🧮 股票估價與好股診斷機（全新實裝）**：
   - **三大正統估價模型**：自動套用「本益比法 (PER)」、「股價淨值比法 (PBR)」、「股息殖利率法」。
   - **階梯式合理價**：自動計算「便宜價 (買進/加碼)」、「合理價 (觀察/持有)」、「昂貴價 (分批停利)」。
   - **明年（次年度）預估目標股價**：精算潛在獲利漲幅空間（%）。
   - **7 大好股票嚴格檢驗清單**：自動審核毛利率 $\ge 40\%$、資本支出/股本 $\ge 40\%$、ROE $\ge 15\%$、負債比 $\le 50\%$、速動比率 $\ge 1.5$、營業利益本業成長、預估 EPS $> 0$。
   - **內建 19+ 檔課堂標的資料庫**：台積電 (2330)、川湖 (2059)、致茂 (2360)、奇鋐 (3017)、鈊象 (3293)、長榮 (2603)、智邦 (2345)、00692、0056、00878、聯發科、廣達、緯穎、雙鴻，以及基亞、宏達電、創見、振樺電、光聖等淘汰對照組；亦支援使用者手動輸入任意股票代號與即時調整財務參數。
2. **🔍 3 天全科速查知識庫**：
   - 22 張全彩結構化知識卡片，涵蓋三大估價模型、黑板手算演練、K線魚板與竹籤技術分析、散戶三大紀律等。
3. **🎙️ 多集完整深度語音大課**：
   - 1121、1114、1107 三天全課程音訊（每集 16~22 分鐘），支援原生音訊播放與播放速度調節。
4. **📄 互動式逐字對照講稿**：
   - 邊聽邊看對照文字，標註時間戳與重點個股目標價速查。
5. **📥 一鍵下載全彩精華手冊 (PDF)**：
   - 包含課堂手寫筆記照片、公式演算法、黑板完整手算版面。
6. **💬 AI 助教對話問答**：
   - 點選快捷問題或語音輸入，即時解答總經與個股策略。

## 🎧 全課程音訊架構（1121 / 1114 / 1107）

1. **1121 EP01 基本面大格局、地緣政治與三大估價法**（約 16~18 分鐘）
   - 大盤 35,738 點破底本質解密、外資摜壓做空手法。
   - 三大國際雜音拆解：Fed 升息、地緣斷鏈、中東產油國財政危機。
   - 「插旗到別人家（Flag-Planting）」到美國設廠的真正意義。
   - 三大估價法核心：股息殖利率法、股價淨值比法、本益比法（Forward EPS）。
2. **1121 EP02 黑板手算大公司、個股實戰、K線魚板竹籤與散戶三大紀律**（約 19~22 分鐘）
   - XQ 三大選股指標門檻（毛利 > 40%、資本支出/股本 > 40%、單位產能獲利）。
   - 黑板手算個股實戰：致茂 (2360) 55.47% 毛利定價權、川湖 (2059) 336.7% 資本支出狂暴擴廠。
   - 焦點個股透視：台積電、奇鋐、鈊象、長榮。
   - K 線心法：魚板與竹籤、回測 1/3 支撐進場點、拉回 17 天無量整理原則。
   - 散戶獲利三大紀律：不追高、設定停利目標、定期定額拆單分散法。
3. **1114 股票風險管理與財務選股**（含手寫筆記算式）：川湖 9% 資本支出率、速動比率 > 1.5、ESG 00692、智邦 2345。
4. **1107 總體經濟與主力操盤**：爸爸是美國、巴菲特指標 260%、M1B/M2 資金黃金交叉。

   ```bash

   git commit -m "Update stock valuation calculator and documentation"
   git push origin main
   ```
